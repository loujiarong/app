# Hello World C++ Project

This project is a simple C++ application that outputs "Hello, World!" to the console.

## Files

- `main.cpp`: Contains the main function that executes the program.
- `README.md`: Documentation for the project.

## How to Compile and Run

1. Open a terminal and navigate to the project directory.
2. Compile the program using the following command:
   ```
   g++ main.cpp -o hello-world
   ```
3. Run the compiled program with the command:
   ```
   ./hello-world
   ```

You should see the output:
```
Hello, World!
```
